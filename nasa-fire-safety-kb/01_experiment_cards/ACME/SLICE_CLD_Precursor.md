# SLICE (ACME CLD Precursor) (ACME)

## 1. Общая информация и научная команда
* **Программа / Направление:** ACME — `Prevention / Fundamental`
* **Модуль / Установка на МКС:** MSG / SPICE
* **Главные исследователи (PI / Co-I):** Marshall B. Long (PI, Yale Univ.); Co-I: Mitchell D. Smooke (Yale Univ.)

## 2. Экспериментальная установка (Hardware & Diagnostics)
ISS Microgravity Science Glovebox (MSG) with SPICE coflow wind-tunnel duct and laminar gas-jet nozzle

## 3. Граничные условия и параметры среды
| Параметр | Значение |
| :--- | :--- |
| **Топливо / Материал** | CH4, C2H4 (diluted with N2) (gas) |
| **Размер образца / горелки** | 1.0-3.2 (nozzle) мм |
| **Режим потока** | `coflow_jet` |
| **Скорость потока** | 5.0 – 40.0 см/с |
| **Давление в камере** | 101.0 – 101.3 кПа |
| **Концентрация $\text{O}_2$** | 21.0 % |
| **Инертные разбавители** | N2 |
| **Предельный кислородный индекс (LOI)** | N/A |

## 4. Ключевые физические явления и результаты
Precursor investigation to ACME CLD Flame conducted in MSG/SPICE; characterized lifted laminar jet diffusion flames, flame stabilization heights, and blow-off/dilution limits in 0g where diluted weak flames remain stable at much lower fuel concentrations than in 1g

## 5. Значение для пожарной безопасности космических аппаратов
Establishes baseline stabilization and dilution blowout limits for gaseous fuel leaks in ventilated spacecraft compartments prior to ACME CIR operations

## 6. Научная преемственность и применение
Direct pathfinder experiment for ACME Coflow Laminar Diffusion Flame (CLD Flame), linking MSG/SPICE diagnostics to ISS CIR ACME hardware
