# ACME CLD Flame (ACME)

## 1. Общая информация и научная команда
* **Программа / Направление:** ACME — `Fundamental`
* **Модуль / Установка на МКС:** CIR (Coflow Burner)
* **Главные исследователи (PI / Co-I):** Marshall B. Long (PI, Yale Univ.); Co-I: Mitchell D. Smooke (Yale Univ.)

## 2. Экспериментальная установка (Hardware & Diagnostics)
ISS CIR with ACME CIA axisymmetric coflow laminar jet burner and optical soot/temperature diagnostics

## 3. Граничные условия и параметры среды
| Параметр | Значение |
| :--- | :--- |
| **Топливо / Материал** | CH4, C2H4 (diluted) (gas) |
| **Размер образца / горелки** | 2.1 (jet) / 25 (coflow) мм |
| **Режим потока** | `coflow_jet` |
| **Скорость потока** | 10.0 – 40.0 см/с |
| **Давление в камере** | 101.0 – 300.0 кПа |
| **Концентрация $\text{O}_2$** | 21.0 % |
| **Инертные разбавители** | N2 |
| **Предельный кислородный индекс (LOI)** | N/A |

## 4. Ключевые физические явления и результаты
Provides steady, flicker-free axisymmetric coflow laminar diffusion flames in 0g up to elevated pressures to isolate soot growth and radiative heat transfer from buoyancy

## 5. Значение для пожарной безопасности космических аппаратов
Supplies high-fidelity validation benchmarks for 2D/3D CFD soot and radiation models used in spacecraft and terrestrial combustion

## 6. Научная преемственность и применение
Part of the 6-experiment ACME suite complementing Flame Design and E-FIELD Flames on soot formation in microgravity
