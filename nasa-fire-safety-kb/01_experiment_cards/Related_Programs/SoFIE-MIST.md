# SoFIE-MIST (SoFIE)

## 1. Общая информация и научная команда
* **Программа / Направление:** SoFIE — `Prevention`
* **Модуль / Установка на МКС:** CIR / SoFIE
* **Главные исследователи (PI / Co-I):** Fletcher J. Miller / NASA GRC SoFIE team

## 2. Экспериментальная установка (Hardware & Diagnostics)
ISS CIR / SoFIE cylindrical flow tunnel with external radiant heaters

## 3. Граничные условия и параметры среды
| Параметр | Значение |
| :--- | :--- |
| **Топливо / Материал** | black cast PMMA rods (+ 0-3.3 kW/m2 radiant flux) (solid) |
| **Размер образца / горелки** | 6.4-12.7 мм |
| **Режим потока** | `opposed_flow` |
| **Скорость потока** | 10.0 см/с |
| **Давление в камере** | 40.0 – 100.0 кПа |
| **Концентрация $\text{O}_2$** | N/A |
| **Инертные разбавители** | N2 |
| **Предельный кислородный индекс (LOI)** | lower_than_1g |

## 4. Ключевые физические явления и результаты
Blue bubble flames and two extinction limits (spread LOC-FS & regression LOC-FR); significantly lower LOC in 0g than 1g

## 5. Значение для пожарной безопасности космических аппаратов
Proves Earth flammability screening is non-conservative for subatmospheric Exploration Atmospheres

## 6. Научная преемственность и применение
Directly extends BASS low-flow 0g solid flammability findings to subatmospheric Exploration Atmospheres (56.5 kPa / 34% O2)
