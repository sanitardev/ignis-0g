# Flame Extinguishment Experiment (FLEX) — Droplet Combustion & Cool Flames in Microgravity

## Программа на одном экране

Программа FLEX (Flame Extinguishment Experiment) исследует горение одиночных топливных капель и массивов капель в условиях микрогравитации на борту МКС с целью понять механизмы подавления пламени и определить минимально необходимые концентрации инертных газов-разбавителей. Её ключевое открытие — обнаружение **невидимых «холодных пламён»** (cool flames), продолжающих гореть после визуального затухания горячего пламени — кардинально изменило понимание риска пожаротушения в космосе. Программа относится к **столпу Suppression (Подавление)** и включает субпрограммы FLEX-1, FLEX-2/CFI, FLEX-2J (JAXA) и FLEX-ICE-GA (ASI/CNR).

---

## Платформа и оборудование

Эксперименты выполнялись в **Combustion Integrated Rack (CIR)** МКС с использованием специализированной вставки **MDCA (Multi-user Droplet Combustion Apparatus)**. MDCA оснащён двумя игольчатыми инжекторами для точного формирования и подвески сферических топливных капель диаметром от 0,5 до 4,2 мм без контакта с поверхностями. Оптическая диагностика включает: цветную видеокамеру высокого разрешения для съёмки горячего пламени, **SSSI-камеру** (Schlieren/backlit) для детектирования невидимых холодных пламён через изменение плотности газа, **пирометр** для измерения температуры поверхности капли, а также многоканальный фотодетектор химической люминесценции (OH*, CH₂O*) для идентификации стадий реакции.

Субпрограмма **FLEX-2J** (JAXA, Principal Investigator Masato Mikami, Университет Яmaguchi) дополнила аппаратуру инжекторами для создания линейных массивов капель (droplet arrays), изучая групповое горение. Итальянская субпрограмма **FLEX-ICE-GA** (ASI/CNR, Patrizio Massoli, CNR-STEMS Милан) сфокусировалась на биотопливных суррогатах и использовала дополнительную спектроскопическую систему для анализа промежуточных продуктов реакции.

## Ключевые открытия

Наиболее значимым результатом программы FLEX стало **первое наблюдение устойчивых квазистационарных невидимых холодных пламён** в условиях микрогравитации (Nayagam et al., *Combustion and Flame*, 159(12):3583–3588, 2012). После того как горячее пламя (T > 1200 К) затухало при снижении концентрации O₂ ниже LOI, капля продолжала гореть окружённая холодным пламенем при температуре ~700 К, невидимой для невооружённого глаза. Этот процесс поддерживается **NTC-кинетикой (Negative Temperature Coefficient)** низкотемпературного окисления, при которой скорость реакции *снижается* с ростом температуры, создавая устойчивый режим «тлеющего» горения.

Эксперименты выявили **двухстадийное горение**: сначала активная фаза горячего пламени с быстрым уменьшением диаметра капли (d²-law), затем фаза медленного испарения в холодном пламени. При повышенных давлениях (> 200 кПа) зафиксированы **осциллирующие «тёплые пламёна»** (warm flames, T ≈ 850–1000 К) с характерной пульсацией, обусловленной конкуренцией NTC-кинетики и теплоотвода. Значение LOI в условиях микрогравитации составило **14–15 % O₂** — на 2–3 % ниже, чем при нормальной гравитации, что означает: горение возможно в атмосфере, которая в 1g уже не поддерживает пламя.

Субпрограмма **FLEX-2J** установила, что в массивах капель (droplet arrays) групповой эффект горения существенно меняет скорость испарения и пределы воспламенения по сравнению с одиночной каплей. **FLEX-ICE-GA** подтвердила, что биотопливные суррогаты (heptane/ethanol и decane/1-hexanol) демонстрируют холодно-пламенное поведение, аналогичное чистым углеводородам, хотя с модифицированными NTC-окнами.

## Значение для пожарной безопасности в космосе

**Критически важное следствие** для бортовых систем пожаротушения: визуальное затухание горячего пламени **не означает прекращения горения**. Холодное пламя невидимо при штатном освещении и не фиксируется стандартными тепловыми датчиками, однако продолжает генерировать токсичные продукты — **CO и формальдегид (CH₂O)** — в концентрациях, опасных для экипажа. Это требует пересмотра алгоритмов работы систем подавления: однократная подача инертного агента (Halon-заменителя или CO₂) без контроля остаточной химической активности может оказаться недостаточной.

Данные FLEX напрямую влияют на проектирование систем пожаротушения для **Artemis, Gateway** и лунных поверхностных баз: в исследовательских атмосферах (56,5 кПа / 34 % O₂) NTC-кинетика работает в более широком диапазоне давлений, что потенциально расширяет область существования холодных пламён. Концентрация инертного агента, необходимая для подавления как горячего, так и холодного пламени, **выше**, чем предполагалось по наземным испытаниям.

## Научная преемственность

FLEX является прямым предшественником субпрограммы **CFI-G (Cool Flames Investigation with Gases)** в рамках **ACME**, которая распространила открытие холодных пламён с жидких капель на **газофазные топливные утечки** — сценарий, принципиально важный для герметичных отсеков. Данные FLEX по NTC-кинетике использованы в качестве валидационной основы для детальных кинетических механизмов в программе **ACME Flame Design**. Масштабные последствия обнаруженных токсичных продуктов горения изучались в программе **Saffire IV–V** при реальных габаритах возгорания в жилом отсеке.
