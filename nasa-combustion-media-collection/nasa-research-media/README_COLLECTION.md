# Сводная коллекция медиаматериалов NASA для 7 исследовательских страниц

Этот архив содержит подготовленные иллюстрации (HD-фотографии) и анимированные демонстрации (GIF), полученные напрямую из медиа-архивов NASA (NASA Image and Video Library, NASA Glenn Research Center, Johnson Space Center).

## Структура папок:
- `01_FLEX_Flame_Extinguishment/` — материалы по горению капель и невидимым холодным пламенам (FLEX / CIR)
- `02_SAME_Smoke_Aerosols/` — материалы по измерению дымовых аэрозолей и детекторам (SAME / MSG)
- `03_BASS_Burning_Suppression_Solids/` — горение тканей и полимеров в потоках вентиляции (BASS / SPICE)
- `04_ACME_Advanced_Combustion/` — комплекс экспериментов с газовой фазой и E-поле (ACME / CIR)
- `05_SoFIE_Solid_Fuel_Ignition/` — горение в атмосфере Artemis/Gateway 56.5 кПа / 34% O2 (SoFIE)
- `06_Saffire_Spacecraft_Fire/` — крупномасштабные пожары внутри корабля Cygnus (Saffire I-V)
- `07_NASA_STD_6001_Baselines/` — нормативная база сертификации и платформы тестирования
- `INDEX_MANIFEST.md` — подробная сводная таблица всех медиафайлов с NASA ID и привязкой к разделам статей

## Лицензия и использование:
Все материалы находятся в общественном достоянии (Public Domain, NASA Media Usage Guidelines).
При публикации на веб-страницах рекомендуется указывать авторство в формате:
`Фото/Видео: NASA / GRC` или `Credit: NASA / Glenn Research Center`.
