# Медиаматериалы: Saffire (Spacecraft Fire Experiment)

Крупномасштабные пожары внутри кораблей Cygnus: ткань SIBAL 40x100 см, токсичные газы CO/HF/HCl.
Соответствующая страница базы знаний: saffire-program.md

  - *Описание:* Крупномасштабное горение структурированного оргстекла (PMMA с ребрами) в Saffire-V внутри Cygnus.
  - *NASA Asset:* GRC-2021-CN-00008
