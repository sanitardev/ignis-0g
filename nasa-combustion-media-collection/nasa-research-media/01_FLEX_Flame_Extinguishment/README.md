# Медиаматериалы: FLEX (Flame Extinguishment Experiment)

Исследование горения капель жидкого топлива и невидимых холодных пламён (cool flames) в микрогравитации на МКС.
Соответствующая страница базы знаний: flex-program.md

## Файлы коллекции:
- **flex_cool_flame_extinction_iss.gif** (Анимированный GIF):
  - *Для раздела:* ## Ключевые открытия
  - *Описание:* Видеокадры эксперимента на МКС — сферическое пламя капли топлива затухает и переходит в невидимое «холодное пламя» (cool flame) при ~700 К.
  - *NASA Asset:* jsc2021m000185_Cool_Flames_Created_Aboard_International_Space_Station
- **flex_mdca_astronaut_karen_nyberg_iss037e004956.jpg** (Фото HD):
  - *Для раздела:* ## Платформа и оборудование
  - *Описание:* Астронавт NASA Карен Найберг выполняет замену вставки MDCA в стойке CIR на МКС.
  - *NASA ID:* iss037e004956
- **flex_mdca_chamber_insert_assembly_iss036e024637.jpg** (Фото):
  - *Для раздела:* ## Платформа и оборудование (Макро-вид)
  - *Описание:* Вставка MDCA CIA с прецизионными иглами для подвешивания капель диаметром 0,5–4,2 мм.
  - *NASA ID:* iss036e024637
- **cir_combustion_integrated_rack_ground_testing_grc_2005_c_00892.jpg** (Фото):

  - *NASA ID:* GRC-2005-C-00892
