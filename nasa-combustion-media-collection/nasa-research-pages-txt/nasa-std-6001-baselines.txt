Нормативная база пожарной безопасности — NASA-STD-6001 и атмосферные стандарты для пилотируемых миссий

Программа на одном экране

Данная страница описывает нормативную базу, а не экспериментальную
программу. NASA-STD-6001 — действующий стандарт сертификации материалов
по пожарной безопасности для всех пилотируемых космических аппаратов
NASA. Критически важно понимать: результаты программ BASS, SoFIE, SAME и
Saffire доказывают, что этот стандарт не является консервативным для
условий микрогравитации и особенно для планируемых исследовательских
атмосфер Artemis и Gateway. Настоящая страница служит точкой отсчёта для
интерпретации всех экспериментальных данных в базе знаний.

------------------------------------------------------------------------

Платформа и оборудование

Настоящая страница описывает нормативные стандарты и атмосферные
определения, а не экспериментальное оборудование. Перечисленные ниже
условия являются базовыми параметрами, используемыми для сравнения с
экспериментальными данными всех программ KB.

NASA-STD-6001B Test 1 (стандартный испытательный стенд): - Вертикальная
ориентация образца (распространение пламени вверх) - Принудительная или
естественная конвекция: 20–30 см/с (типичная скорость восходящей
конвекции при 1g) - Атмосфера: 101,3 кПа, 21 % O₂ - Нагревательный
элемент поджига: стандартная горелка - Критерий: отсутствие
распространения пламени за пределы образца

Ключевые открытия (нормативный анализ)

Несоответствие Test 1 реальным условиям МКС. Программа BASS
экспериментально установила, что HVAC-поток МКС (5–20 см/с)
соответствует «наиболее опасной зоне» U-образной границы
воспламеняемости в микрогравитации. Test 1 воспроизводит условия с
естественной конвекцией 20–30 см/с при 1g, что в плоскости
«скорость–концентрация O₂» соответствует верхней ветви U-кривой — режиму
термического сдувания пламени. Таким образом, Test 1 тестирует материал
в режиме, близком к гашению, тогда как реальная МКС создаёт условия
максимальной горючести. Материал, едва прошедший Test 1, может легко
гореть в штатной вентиляционной среде МКС.

Критическое значение Limiting Oxygen Index (LOI) в 0g. Три независимые
программы зафиксировали, что LOI в микрогравитации ниже на 2–4
процентных пункта по сравнению с 1g: - FLEX: LOI капель гептана = 14–15
% (против ~17 % при 1g) - BASS: SIBAL горел при 13,6 % O₂ (против ~16 %
при 1g) - SoFIE-MIST: LOC при 56,5 кПа / 34 % O₂ ниже на 4–8 п.п.
относительно 1g

Исследовательская атмосфера (Exploration Atmosphere): обоснование и
риски. EAWG (Exploration Atmospheres Working Group) рекомендовала
атмосферу 56,5 кПа / 34 % O₂ для миссий Artemis и Gateway по
физиологическим причинам: при этих параметрах время предварительного
дыхания O₂ перед выходом в открытый космос (ВКД) сокращается с 4 часов
до 30 минут, что критически важно для эффективности лунных ВКД. Однако
повышение концентрации O₂ с 21 % до 34 % значительно расширяет границы
воспламеняемости большинства полимерных материалов, а снижение давления
изменяет кинетику пламени. Программа SoFIE предоставляет единственные
доступные микрогравитационные данные для этой атмосферы.

Скорость HVAC как критический параметр. Данные BASS и ACME BRE
указывают, что для исследовательских атмосфер необходима переработка
концепции вентиляционного управления пожаром. При 34 % O₂ молекулярной
диффузии O₂ достаточно для поддержания горения даже при полном
отключении вентиляции (результат BRE). Таким образом, стратегия «отключи
HVAC и дождись самогашения», применяемая на МКС, может быть неэффективна
в Gateway.

------------------------------------------------------------------------

Значение для пожарной безопасности в космосе

Совокупность экспериментальных данных KB формирует однозначный вывод:
NASA-STD-6001B в редакции 2016 года не обеспечивает консервативную
сертификацию материалов ни для условий МКС (низкая скорость HVAC), ни
для условий Artemis/Gateway (пониженное давление, высокий O₂).
Необходима разработка дополнительных тестовых методологий:

1.  Тест при низкой скорости потока (5–15 см/с) для эмуляции HVAC МКС —
    предложен по результатам BASS
2.  Тест в исследовательской атмосфере (56,5 кПа / 34 % O₂) для
    Gateway/лунной базы — обосновывается данными SoFIE
3.  Многомодальный детекторный стандарт — по результатам SAME и Saffire

Эти изменения находятся на стадии обсуждения в рамках подготовки
редакции NASA-STD-6001C при активном участии данных из экспериментальных
программ KB.

------------------------------------------------------------------------

Научная преемственность

Данная нормативная страница является центральным узлом базы знаний:
каждая экспериментальная программа либо выявила несоответствие стандарту
(BASS, SoFIE, SAME), либо предоставила данные для его обновления (FLEX,
ACME, Saffire). Маршрут нормативной эволюции: NASA-STD-6001A (1994) →
NASA-STD-6001B (2016, текущий) → NASA-STD-6001C (ожидается, основан на
данных KB 2010–2025).
